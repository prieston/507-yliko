# Ενότητα 1: αλγόριθμοι και πολυπλοκότητα

## Εργαστήριο 3: από τη σκέψη στη σελίδα

Το πρώτο εργαστήριο στους υπολογιστές. Στήνετε το περιβάλλον που θα χρησιμοποιούμε σε όλα τα επόμενα εργαστήρια. Δεν χρειάζεται κανένα αρχείο από εδώ.

### Βήματα

1. Λογαριασμός στο GitHub.
2. Νέο repository με όνομα `507-algdb`, **Public** (αλλιώς δεν δουλεύει το GitHub Pages).
3. Από το κουμπί Code του repository: Codespaces, Create codespace. Ανοίγει VS Code στον browser με τον βοηθό (agent) δεξιά.
4. Στη συνομιλία με τον βοηθό περιγράφετε τον αλγόριθμο σε τέσσερα μέρη: **είσοδος, βήματα, έξοδος, έλεγχοι**. Ο βοηθός γράφει τον κώδικα.
5. Commit και Sync Changes.
6. Settings, Pages, Deploy from a branch, `main`, `/ (root)`, Save. Η σελίδα σας είναι στο `https://ΟΝΟΜΑ.github.io/507-algdb/`.

### Η άσκηση: το ψηλότερο σημείο

Σελίδα `enotita-1/psilotero.html` που βρίσκει το ψηλότερο από πέντε σημεία και μετράει πόσες συγκρίσεις έκανε.

| Σημείο | Z (m) |
|---|---|
| P1 | 412.3 |
| P2 | 418.0 |
| P3 | 409.9 |
| P4 | 421.5 |
| P5 | 415.2 |

Πριν τρέξετε οτιδήποτε, ξέρετε τι περιμένετε: ψηλότερο το **P4**, με **4 συγκρίσεις** (Ν−1, κρατάω τον καλύτερο).

Επέκταση για όσους τελειώνουν: η απάντηση «όλα με όλα», που για 5 σημεία κάνει 20 συγκρίσεις. Συγκρίνετε τους δύο μετρητές.
