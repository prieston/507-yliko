## Πώς είναι οργανωμένο

Ένας φάκελος ανά ενότητα του μαθήματος. Κάθε φάκελος έχει ένα `README.md` με τις οδηγίες κάθε εργαστηρίου της ενότητας και τα αρχεία δεδομένων που χρειάζεστε.

| Φάκελος | Ενότητα | Εργαστήρια |
|---|---|---|
| [enotita-1](enotita-1/) | Αλγόριθμοι και πολυπλοκότητα | Εργαστήριο 3: το repository 507-algdb, Codespaces, GitHub Pages, ψηλότερο σημείο |
| [enotita-2](enotita-2/) | Δίκτυα και διαδρομές | Εργαστήριο 4: από τον χάρτη στο γράφημα (`dromoi.js`) <br> Εργαστήριο 5: ο χάρτης του campus και ο Dijkstra (`campus.js`) |

## Πώς παίρνετε ένα αρχείο στο Codespace σας

Από το terminal του Codespace, με το raw URL του αρχείου. Για παράδειγμα:

```
mkdir -p enotita-2
curl -o enotita-2/campus.js https://raw.githubusercontent.com/prieston/507-yliko/main/enotita-2/campus.js
```

ή λέτε στον βοηθό «κατέβασε το αρχείο από αυτό το URL στον φάκελο enotita-2».

## Η δουλειά σας

Ό,τι φτιάχνετε μπαίνει στο δικό σας repository `507-algdb`, στον φάκελο της ίδιας ενότητας (π.χ. `enotita-2/campus.html`), και παραδίδετε τον σύνδεσμο GitHub Pages. Μπορείτε να χρησιμοποιείτε τον βοηθό ελεύθερα, αλλά το παραδοτέο είναι δικό σας: πρέπει να μπορείτε να εξηγήσετε κάθε γραμμή του.
